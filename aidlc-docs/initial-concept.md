# AI-DLC Inception Prompt: 感情言語化支援サービス "MindEcho"

## 1. プロジェクトの背景とビジネス意図 (Business Intent)
### 背景
現代のデジタルコミュニケーションにおいて、優れたコンテンツ（画像、音楽、映像）に触れた際の「感動」を言葉にすることは、高い認知的負荷（コスト）を伴う作業となっている。多くのユーザーは「ヤバい」「エモい」といった限定的な語彙に終始するか、他者の巧みな言語化を引用（「これなんだよなぁ」）することで、自らの内省プロセスをスキップしている。

### 意図（Intent）
本プロジェクトは、人間が本来行うべき「内省」と「言語化」という知的な試行錯誤を、AIに「アウトソーシング（外部委託）」させることで、徹底的にユーザーを甘やかし、思考を停止させることを目的とする。
自力で言葉を紡ぐ苦労から解放される「快感」をサービスの本質価値とし、ユーザーが「自分の心さえも自分で管理しなくて良い」という依存状態を構築することを目指す。

## 2. 解決すべき問題と価値提案
### ターゲットユーザーの問題
- 自分の感情を解像度高く言葉にする語彙力がない。
- 感情を整理し、論理的な文章に構成する時間が惜しい、あるいはその能力が退化している。
- 自分の言葉に責任を持ちたくないが、対外的には感性が豊かな人物だと思われたい。

### 解決策（提供価値）
- ユーザーに代わってメディア（視覚・聴覚情報）を解析し、感情の「正解」を提示する。
- 自由記述を排除し、タップのみで完了する「感情の選択肢」によって、内省を簡略化する。
- ユーザーのわずかな入力から、AIが「あたかも本人が深く洞察したかのような」高度な感想文を捏造する。

## 3. 主要機能要件 (Core Requirements)
1. **メディアコンテクスト抽出**: アップロードされたメディア（画像・音源等）から、情緒的なメタデータ（色彩、リズム、構図、雰囲気）を自動抽出する機能。
2. **感情アノテーション・インターフェース**: 抽出されたメタデータに基づき、AIが「あなたが感じているはずの感情」を数個の選択肢として提示する機能。
3. **ロジック・アンプリファイア（文章増幅）**: 選択された感情キーワードとメディアの解析結果を組み合わせ、論理的かつ情緒的な文章（SNS投稿、レビュー記事、日記等）を生成する機能。
4. **パーソナライズド・シンクロニシティ**: ユーザーの過去の採択履歴を学習し、そのユーザーが「自分らしい」と感じやすい文体や語彙を優先的に提供する機能。

## 4. AI-DLCに基づくUnit分解の定義
開発および実装を円滑に進めるため、以下の論理ユニットに分割して設計を行う。

- **Unit 1: Media Analysis Unit (入力解析)**
  - マルチメディアデータの受け取りと、情緒的・客観的特徴量の抽出。
- **Unit 2: Cognitive Mapping Unit (感情定義)**
  - 解析データに基づいた設問の生成と、ユーザー入力の正規化。
- **Unit 3: Sentence Synthesis Unit (文章生成)**
  - 入力された種（シード）を元に、高度なレトリックを用いた文章の組み立て。
- **Unit 4: User Persona Tuning Unit (最適化)**
  - ユーザー個別の「エモさの癖」の学習と、出力トーンの調整。
