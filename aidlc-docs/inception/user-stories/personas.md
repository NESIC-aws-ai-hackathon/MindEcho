# User Personas - MindEcho

## Persona 1: ユキ（カジュアルSNSユーザー）

| 項目 | 内容 |
|---|---|
| **名前** | ユキ |
| **年齢** | 22歳 |
| **職業** | 大学生 |
| **ITリテラシー** | 高（スマホネイティブ、SNS常用） |
| **特徴** | 映画や音楽に触れた際の感動をSNSで発信したいが、「ヤバい」「エモい」以上の語彙が出てこない |
| **ゴール** | 短時間で気の利いたSNS投稿文を作成し、フォロワーから共感を得たい |
| **モチベーション** | 感性豊かな人物として見られたい欲求、言語化の労力からの解放 |
| **フラストレーション** | 自分の語彙力の限界、他人の巧みな表現への羨望、感想を書く時間の惜しさ |
| **利用メディア** | 画像（写真・イラスト）、音楽 が中心 |

## Persona 2: タケシ（コンテンツレビュアー）

| 項目 | 内容 |
|---|---|
| **名前** | タケシ |
| **年齢** | 35歳 |
| **職業** | 会社員（副業ブロガー） |
| **ITリテラシー** | 中〜高 |
| **特徴** | 漫画・小説のレビュー記事をブログに定期投稿しているが、記事1本に数時間かかるのが悩み |

| **モチベーション** | ブログのPV向上、質の高いアウトプットの効率的な量産 |
| **フラストレーション** | 感想の言語化に時間がかかりすぎる、構成力への自信のなさ |
| **利用メディア** | 漫画、小説 が中心、画像も利用 |

## Persona 3: ミサキ（内省記録ユーザー）

| 項目 | 内容 |
|---|---|
| **名前** | ミサキ |
| **年齢** | 28歳 |
| **職業** | デザイナー |
| **ITリテラシー** | 高 |
| **特徴** | 日常で触れるアート作品や音楽の感想を日記として記録する習慣がある。言語化は好きだが時間が限られている |

| **フラストレーション** | 忙しくて記録をサボると感情の鮮度が失われる |
| **利用メディア** | 画像（アート作品）、音楽、小説 |

## Persona 4: リョウ（インディーズ音楽批評家）

| 項目 | 内容 |
|---|---|
| **名前** | リョウ |
| **年齢** | 26歳 |
| **職業** | レコードショップ店員（音楽ブログ運営） |
| **ITリテラシー** | 中〜高 |
| **特徴** | インディーズ音楽の深い知識を持ち、音楽ブログやSNSで批評記事を定期的に執筆。音楽の細かなニュアンス（音像、歌詞の世界観、ジャンル横断的文脈）を言語化したいが、毎回精密な文章を書くのに時間がかかる |
| **ゴール** | 音楽の印象や感情的インパクトを迅速に言語化し、質の高い批評記事の下書きを得たい |
| **モチベーション** | インディーズアーティストの魅力を広めたい、音楽コミュニティでの発信力向上 |
| **フラストレーション** | 感じたことを精確に言語化するのに時間がかかる、「良い」だけでは伝わらない音楽の魅力をどう言葉にするか |
| **利用メディア** | 音楽が最優先、アーティストのジャケット画像も利用 |
